VEDIC EDUCATIONAL SERVICES — WEBSITE
===================================

How to run:
1. Extract the ZIP.
2. Open the folder in VS Code.
3. Open index.html in a browser, or use the VS Code Live Server extension.
4. All main pages are linked:
   - index.html
   - about.html
   - services.html
   - study-abroad.html
   - blog.html
   - contact.html

Important:
- The supplied Vedic services poster and fixed Vedic Educational Services logo are included locally in assets.
- The site is built with HTML, CSS and vanilla JavaScript. No framework is required.
- No external image CDN is required for the supplied visual assets.
- Replace the placeholder contact details once the official phone, WhatsApp, email and address are available.
- The contact form is front-end only. Connect it to your preferred form/CRM/email/WhatsApp backend before publishing.
